# 🚀 Presensi Digital - Team Yayubi

Sistem terminal presensi pameran PJBL ultra-responsif dan futuristik yang terintegrasi langsung dengan database Google Sheets via SheetDB API.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Premium Glassmorphism), JavaScript (Fetch API JSON)
- **Database Backend:** Google Sheets & SheetDB API
- **Deployment:** Vercel
