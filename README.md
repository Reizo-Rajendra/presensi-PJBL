Sistem Terminal Presensi Digital berbasis web dengan desain futuristik, adaptif, dan ultra-responsif yang dirancang khusus untuk kebutuhan **Booth Pameran Project-Based Learning (PJBL) Expo 2026**. 

Sistem ini mengamankan data kehadiran interaktif pengunjung secara *real-time* langsung ke database penyimpanan awan tanpa memerlukan setup backend yang rumit.

---

## ✨ Fitur Unggulan

* 🛸 **Premium Cyberpunk UI:** Tampilan visual kelas industri dengan sentuhan *Glassmorphism*, efek *neon glow dynamic*, dan skema warna gelap premium yang memanjakan mata.
* 📱 **Mobile-First Optimization:** Responsivitas mutlak yang dijamin anti-cacat saat diakses melalui perangkat HP (Android/iOS) milik pengunjung pameran.
* ⚡ **Real-Time Database Sync:** Integrasi Fetch API berbasis JSON objek yang mengunci data secara instan tanpa kegagalan pemrosesan string teks.
* 🏆 **Dynamic Visitor Summary:** Menampilkan ringkasan data otentik pengunjung tepat setelah proses *Check-In* berhasil dilakukan.

---

## 🛠️ Tech Stack (Arsitektur Sistem)

Proyek ini dibangun menggunakan teknologi web standar industri demi performa dan kecepatan muat maksimal:

* **Frontend:** HTML5 (Semantic Structure) & CSS3 (Custom Properties & Keyframe Animations)
* **Fonts & Icons:** Plus Jakarta Sans & FontAwesome v6 Core
* **Database Driver:** SheetDB API Wrapper
* **Cloud Storage:** Google Sheets Engine
* **Deployment Platform:** Vercel Production Server
